# Quiz Marketing Digital — Fête de la Science

## Ouvrir dans VS Code

1. Décompressez le dossier.
2. Ouvrez le dossier `quiz-marketing-digital` dans VS Code.
3. Ouvrez `index.html`.
4. Lancez-le avec l'extension **Live Server** (recommandé), ou ouvrez simplement `index.html` dans un navigateur.

## À noter

Le projet est actuellement un site HTML autonome : le CSS et le JavaScript sont intégrés dans `index.html`.
Il utilise des ressources externes via CDN pour Tailwind CSS, Font Awesome, Google Fonts et Canvas Confetti.
